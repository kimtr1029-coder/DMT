**Suggested caption.** Register-transfer architecture of the per-QAM margin search. The active four-word Q16 register m drives one shared 255-tone scan, which returns loaded bits B, target pass, and worst tier j_w to the FSM. The FSM includes a 4→16→64→256 trial index counter and best-score registers B* and found. In UP, the source MUX selects m, the index is j_w, and the shared ALU adds Δ. In TRIAL, the MUX selects the saved base m0, the counter provides j, and the ALU subtracts Δ, if m0,j≥Δ. A four-to-one lane read and one-to-four insertion unit alter only coordinate j while the other three lanes bypass arithmetic. The writeback MUX loads the new vector, restores m0, or commits m*. The UP passing vector is snapshotted into m0. A passing trial captures current m into m* only if no earlier feasible trial exists or B>B*. At sweep end the FSM commits m* if found, otherwise restores m0. Solid paths are four-word data or scan status; dashed paths are control. The named best_we control pin on the best register is driven by the identically named FSM output. Vector PDF width: 170 mm.
